## 中文

PickSnap 1.4.1 让浏览选片和批量操作更顺手，并修复检索模型下载与匿名统计客户端问题。

- 排序：按拍摄时间、文件名、星级或分数升降序浏览，记住排序偏好。
- 多选与批量评星：选择多张照片，一次设置或清除星级，并支持撤销。
- 导出所选：直接导出当前选中的照片副本，可按需要开启 XMP 侧车。
- 仅导入 RAW：新建任务时可只导入 RAW；目录没有 RAW 时提示并回退普通导入。
- 检索模型下载：修复可用来源配置及部分 TLS 连接中断的重试处理。检索模型国内包使用 hf-mirror，国际包使用 Hugging Face；镜像服务可能跳转至其下载 CDN，首次下载需要联网。
- 匿名统计客户端：补充应用 User-Agent，改善 403 响应后的退避重试及固定格式错误诊断；匿名统计仍可关闭。

照片处理在本机进行，原片保持不变。Mac 包适用于 Apple Silicon（arm64），Windows 包为 x64。请根据地区选择 cn 或 global 包，并使用 SHA256SUMS.txt 校验下载。

## English

PickSnap 1.4.1 improves photo browsing and batch selection, and fixes search-model downloads and the anonymous usage statistics client.

- Sort photos by capture time, filename, rating or score in ascending or descending order, with saved sorting preferences.
- Select multiple photos, apply or clear star ratings in one operation, and undo a batch rating change.
- Export copies of the selected photos, with optional XMP sidecars.
- Import RAW files only when creating a task. If the folder has no RAW files, PickSnap shows a notice and falls back to normal import.
- Fix available source configuration for search-model downloads and retry handling for some interrupted TLS connections. The cn packages use hf-mirror for search models; global packages use Hugging Face. Providers may redirect downloads to their CDNs. Initial model downloads require internet access.
- Add an application User-Agent and improve backoff after HTTP 403 responses and fixed-format diagnostics in the anonymous usage statistics client. Anonymous statistics can still be disabled.

Photo processing stays on your computer and original files remain unchanged. Mac packages target Apple Silicon (arm64); Windows packages target x64. Choose the cn or global package for your region and verify downloads with SHA256SUMS.txt.
