# PickSnap Releases

Official public release distribution channel for [PickSnap](https://picksnap.eascivo.com/) by Eascivo Studio.

PickSnap is a local photo culling workspace for macOS and Windows.

## Downloads temporarily paused

PickSnap 1.3.3 has been withdrawn because changed legacy task records can prevent startup after migration. Its release and installation packages have been removed. We are preparing 1.3.4.

If you already installed 1.3.3, keep your task data. If the app will not open, contact support@eascivo.com for recovery help. Reinstalling or deleting task records is not required to preserve your work.

See the [official download status](https://picksnap.eascivo.com/download/) for updates. Older releases remain historical versions and are not a recovery method for a 1.3.3 database.
